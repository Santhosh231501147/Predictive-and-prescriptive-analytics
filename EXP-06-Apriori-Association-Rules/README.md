# Apriori Algorithm for Association Rule Mining

## Aim
Apply the Apriori algorithm on transaction data to find frequent itemsets and association rules.

## Dataset
Market basket transaction dataset

## Professional Improvements
- Encodes transactions into basket format.
- Extracts frequent itemsets and association rules.
- Ranks rules by confidence, support, and lift.

## How to Run
Open `code.ipynb` in Google Colab or Jupyter and run all cells from top to bottom. The notebook regenerates the files under `results/`.
