# Missing Value and Outlier Analysis

## Aim
Analyze missing values, fix missing data, and detect outliers in a dataset.

## Dataset
Synthetic retail/customer dataset

## Professional Improvements
- Reports missing percentage per variable.
- Applies typed imputation strategies for numeric and categorical features.
- Detects outliers using the IQR rule and exports a clean dataset.

Open `code.ipynb` in Google Colab or Jupyter and run all cells from top to bottom. The notebook regenerates the files under `results/`.
